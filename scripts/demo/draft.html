How a page view is recorded

One visit to /pricing, followed from the browser to the database.

  1. Trackerposts on page load
    POST /api/send
{ type: "event", payload: { url: "/pricing",
  referrer: "https://news.ycombinator.com/" } }
  2. Send APIchecks, then reads the client
    isbot(userAgent)   → false
hasBlockedIp(ip)   → false
getClientInfo()    → chrome, Mac OS, laptop, DE
  3. Sessionsfinds the visit, or starts one
    sessionId 7c1e… (new)   visitId 2b90…
  4. Event queriesone row per page view
    eventType 1 (page view)   urlPath "/pricing"
referrerDomain "news.ycombinator.com"
